# Current limitations

The offline CLI joins supplied manifest/notes/advisory inputs to static reports.
Independent finished-app review and full product acceptance remain pending.
Synthetic workflow controls do not establish semantic or live-model quality.

Version arithmetic requires pinned npm semver and native Node. The five-second
operation deadline includes startup, locking and IPC. Missing Node, timeouts and
malformed output remain unknown/incomplete. The persistent helper has lifecycle
controls. Earlier Node failures and a test-collection collision remain historical
failures; a later corrected tests-plus-vendor run passed separately.

Application intake is one explicit local JSON bundle, capped at 64 MiB, with at
most twenty selected direct packages, 500 processed spans and 1,000 supplied
advisory records. Original JSON member text and notes remain hash-bound.
Individual component bounds also apply. Capped, malformed, missing and held
items remain visible. A missing advisory snapshot is not an empty successful
query.

The keyword baseline is uncalibrated and can flag internal changes or miss changes
without keywords. Typed/generative builders exist, but offline application runs
return unavailable for those methods. No installed live SDK path, genuine model
quality, selected thresholds or model evaluation is claimed. Rule screening does
not establish injection robustness.

Advisory membership is separate from conditional usage. Outside-range and
wrong-identity cases need no usage call. In-range cases needing interpretation
remain unknown until an actual usage path is available. Snippets cannot prove
repository-wide reachability or that a target is globally safe. Source conflicts
and withdrawal remain disclosed.

Cited schemas and row codecs are structural contracts. A resolved quote proves
literal source fidelity under explicit policies, not semantic truth, authenticity,
approval or ownership. Semantic findings remain partial. Schema pair constraints
do not replace runtime checks for ordered/unique line maps or actual raw/derived
bytes. Generic models do not install every domain resolver or reproduce their
owning source producers.

Shared offline controls use explicit synthetic data. Mock/replay origin, source
cost/latency, missing usage and zero new spend remain distinct; they are not live
API or benchmark evidence. Real HTTP/DNS/socket acquisition is not wired into
this CLI. Bounded injectable protocols and saved inputs do not establish a live
transport.

There is no server, listener, Docker stack, database, auth, migration, edge
function, hosted backend or deployment. Python/Node analysis runs locally; its
standalone report is a static artifact. The staged-secret guard is bounded and
cannot guarantee detection of every secret format. Offline demos need no keys.

The supported quickstart uses a source checkout with its pinned npm dependency.
Detached source-closure checks exercise the actual normal/refusal CLI; a Python
wheel installation and hosted execution have not been qualified. Static reports
are portable artifacts, not an installed analysis service.
