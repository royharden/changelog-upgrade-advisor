# App judgment layer

Every selected literal entry has a closed input with original source identity,
bounded context and optional usage snippet. The plain keyword baseline is an
uncalibrated regex classifier; it can flag internal removals and miss changes
without keywords. These weaknesses are explicit controls, not quality results.
Pure deprecation alone does not make that baseline breaking.

The model builders use the actual shared S3 types: three Noul questions and one
six-option Choice, or structured generation capped at 512 output tokens. Version
arithmetic stays outside model state. Category and breakingness stay separate;
typed usage is unknown pending a separately accounted usage judgment. Noul's 0.5
classification boundary is fixed representation, not a selected accept threshold
or calibration claim. Raw probabilities remain available for later review bands.

Canonical S6 rules screen all entry, context and snippet text before requests are
built. A hold retains the entry as review with no request. A rule pass is no
injection-robustness guarantee. Both model methods see the same original bounded
entry; no keyword prefilter drops entries. Wrapped DATA and category order are
included in the original request identity.

The offline executor accepts only an actual S3 mock/strict-replay provider and the
caller's existing ledger, budget, context, limits and allocation. It performs no
admission or auxiliary calls. Native context must bind the input, policy, source
generation and span. Request, policy and source mutations fail closed. Native
prepared-request and source-capture identities must match before decoding. The
layer refuses live-origin input; funded live app judgments remain unqualified.

The optional `execute_native_simulation` entry uses the same caller-owned six
accounting arguments and exact canonical S3 SDK mock transport. It permits only
injected simulation with one attempt and no content repair. It does not admit an
operation, read credentials or enable a live CLI path. A caller skipping an
already-funded conditional child must close it with the canonical undispatched
proof; a validation refusal before dispatch leaves cancellation with that caller.

Mock wire requests run the actual pinned SDKs inside a bounded owned worker.
Generation/typed answers still pass this layer's source/request/schema checks.
If a closed producer error occurs after `run` begins, the consumer returns an
unavailable judgment, retains the allocation reference, labels mock origin, and
keeps unknown attempt IDs/usage null. An empty reported attempt sequence remains
distinct from unknown IDs. No capture, model latency or settled charge is invented;
the actual ledger retains conservative liability. This is simulation accounting,
not a real provider observation or independent product acceptance.

Returned span IDs, enums, extra actions, booleans, probabilities and optional free
quotes are validated. Displayed quotes are always copied from the original entry;
a generated free quote must be a literal substring or the entire judgment fails.
Missing snippets cannot establish usage impact. Errors, unavailable methods and
held entries retain their original span and denominator. Successful semantics
still need actual cited resolution and remain partial; wire success is no
acceptance or semantic truth guarantee.

Offline controls use explicitly synthetic S3 captures with actual zero-quota
ledger admission. They preserve mock provenance, nullable usage, original
capture cost/latency, zero current external cost and no dispatch. No corpus,
DEV selection, threshold grid, fit, calibration, model benchmark, paid campaign
or heldout experiment is performed by these tests. Genuine Jev and generative
accuracy remain unmeasured until the actual adapter and testing gates are met.
